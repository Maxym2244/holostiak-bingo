# Холостяк 15 · Карта експерта (веб-версія)

Статичний сайт без збірки (HTML + CSS + JS). Усі 5 сторінок з оригіналу: карта експерта, лімузини 01–15 і 16–30, бінго, підсумки & крінж.

- Кожне поле — інпут / зафарбовування / перемикач.
- Лічильники «паличка щоразу, коли…» мають + і −. У клітинок бінго тап додає +1 (×2, ×3…), кнопка «−» або правий клік віднімає.
- Бінго рахує закреслені клітинки й зібрані ряди та стовпчики. Коли збереться лінія, з’явиться «БІНГО!».
- Кожен має свою картку. Вгорі перемикач гравців: чужу картку видно наживо, але тільки для перегляду.

## Запуск локально

```bash
python3 -m http.server 8000   # потім відкрити http://localhost:8000
```

Без налаштування Firebase сайт працює в «локальному режимі»: дані лежать тільки в цьому браузері.

## Синхронізація між вами (безкоштовно)

> Уже налаштовано: проєкт Firebase `holostiak-bingo` (Realtime Database, регіон europe-west1), правила опубліковані, конфіг лежить у `firebase-config.js`. Нижче — як це відтворити з нуля.

1. <https://console.firebase.google.com> → **Add project** (Analytics не потрібна).
2. **Build → Realtime Database → Create database** (регіон будь-який, режим *locked*).
3. Вкладка **Rules** → встав і натисни Publish:
   ```json
   { "rules": { "rooms": { "$room": { ".read": true, ".write": true } } } }
   ```
   Доступ мають лише ті, хто знає код кімнати, тож вигадай довгий код.
4. **Project settings → General → Your apps → Web (`</>`)** → скопіюй `firebaseConfig` у `firebase-config.js`. Обов’язково потрібен `databaseURL`.
5. Обоє відкриваєте сайт, вводите **однаковий код кімнати** і **свої імена**. Кнопка ⚙ → «Скопіювати посилання-запрошення» дає лінк із готовим кодом.

Той самий код кімнати й ім’я на іншому пристрої відновлять твою картку.

## Безкоштовний хостинг

Підійде будь-який статичний. Найпростіше **GitHub Pages**: створи репозиторій, залий туди ці файли, потім *Settings → Pages → Deploy from branch → main / root*. Сайт буде на `https://<user>.github.io/<repo>/`.
Альтернативи: Cloudflare Pages, Netlify, Firebase Hosting.
